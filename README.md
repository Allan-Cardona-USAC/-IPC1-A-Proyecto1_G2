<h1 align="center" ; color= red ; >PROYECTO FINAL "PopCornFlix"</h1>
Se le ha encargado desarrollar una plataforma web que brinde servicios de streaming para
alquiler de películas, llamada PopCornflix. En un contexto donde las plataformas de
streaming han experimentado un notable auge en popularidad, se busca aprovechar esta
tendencia mediante la creación de una plataforma propia. Esta plataforma tiene como
objetivo principal administrar una amplia gama de funciones para garantizar una experiencia
de entretenimiento de alta calidad para los usuarios. Se espera que su equipo implemente
características clave que permitan la gestión eficiente del contenido, la interacción de los
usuarios y la administración de cuentas.
